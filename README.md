# dqct-v2

## Docker启动指南

- 本指南将引导您通过几个极其简单的步骤，在您的电脑上运行此项目
- **无需**安装 Python、Node.js 或任何复杂的环境，**唯一需要的是 Docker**
- 请在您的电脑（Windows, macOS, 或 Linux）上安装并运行 **[Docker Desktop](https://www.docker.com/products/docker-desktop/)**
- 安装完成后，然后请确保它已经启动

### **第一步：解压文件**

-   将 `.zip` 或 `.rar` 的项目压缩包文件，解压到您电脑的任意位置

### **第二步：配置您的 API 密钥**

1.  进入刚刚解压出来的项目文件夹，你会看到一个名为 `env.example` 的文件
2.  **复制**这个文件，并**粘贴**在当前项目文件夹，然后将副本**重命名**为 `.env` 
3. 然后打开这个新的 `.env` 文件。替换为您自己的真实密钥，然后保存并关闭文件

### **第三步：启动项目**

在项目根路径下，打开终端，使用一个命令来启动所有服务。

```bash
docker-compose up --build -d
```

1.  顺利的话，您会看到终端开始滚动很多日志，这是 Docker 正在为您自动构建和启动应用。这个过程在第一次运行时可能需要几分钟，请耐心等待。
2.  当日志滚动停止，并且最后出现类似 `... done` 或 `... running` 的字样时，就代表平台已在后台成功启动！

### **第四步：访问平台**

-   此时，打开您的网页浏览器，在地址栏输入并访问:  **`http://localhost:8080`**

### **如何停止？**

- 如果您想关闭系统，回到刚才的终端窗口，输入以下命令并按回车即可：

```bash
  docker-compose down
```
